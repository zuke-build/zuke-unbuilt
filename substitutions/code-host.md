# Code host

## What the original used

GitHub, with GitLab, Azure DevOps and Bitbucket also supported; reviews could post as a dedicated app identity, and author trust came from the host's author-association metadata.

## What a replacement must provide

Change-request comments and line threads, an author trust attribute set by the host, and a bot identity the reviewer can recognise as itself.

## Known alternatives

Any forge with a review API.

## How to tell it is right

The untrusted-rebuttal and pasted-marker scenarios pass.
